# SpendWise - Make Spendwise Interactive
A simple,interactive expense tracker that helps you track spending, stay within budget, and understand where your money goes.
## Project Overview
spendWise started as a static page that only showed information and logged results in the browser console. This week it was upgraded into a fully interactive web application where users can add expense, set a budget, filter expenses, delete expenses, and see the dashboard upgrade instantly on the page.
## What Improvement Were Made to SpendWise This Week
1. Added an expense form: Users can now add a new expense by entering a name, amount, and category (food, Transport, Shopping,Entertainment, Other) instead of hard-coding expenses in JavaScript.
2. Live Dashboard: Added Total Spent, Budget, Remaining, and Status cards that update automatically whenever an expense is added, deleted, or the budget is changed.
3. Budget Control: Users can change their monthly budegt using the budget input and update Budget button.Th default budget is KES 5000.
4. Category Filtering: Added filter button(All, Food, Transport, Shopping, Entertainment, Other) so users can view only one category at a time.
5. Delete and clear: Users can delete a single expense with the delete button, or remove all expenses with clear All button.
6. Smart Insight Message: The app shows personalized advice, like warning when you are close to your budget or telling you which category you spend the most on.
7. Better Styling: Improved layout with cards, colors for over budget/ warning/good status and a responsive design that works on phone and computer.
